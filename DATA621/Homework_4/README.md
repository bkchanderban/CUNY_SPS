# DATA 621 – Homework #4: Insurance Risk Analysis

This folder contains the datasets and R code for Homework #4 of DATA 621: Business Analytics and Data Mining at CUNY SPS.

The assignment involves using binary logistic regression to predict automobile crash probabilities and multiple linear regression to estimate associated crash costs.

## Datasets

- `insurance_training_data.csv` – Training data for model development and evaluation.
- `insurance-evaluation-data.csv` – Evaluation data for generating final predictions.
